# Frontend (workstream B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or
> superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build the one-page, mobile-first UI: the create form, the list of my links, and the detail sheet. It runs
against the tRPC contract from the foundation plan. The procedures are stubs until workstream C lands, and nothing
here changes when they become real.

**Architecture:**
- `app/page.tsx` is a Server Component. It prefetches `links.list` in-process and hydrates the client.
- The form, the list and the sheet are Client Components.
- Pure formatting and error logic lives in tested helpers, so the components stay thin.

**Tech Stack:** Next.js 16 App Router, tRPC 11 with `@trpc/tanstack-react-query`, TanStack Query 5, Tailwind v4,
shadcn/ui (Radix), lucide-react, `next/font`.

**Spec:** `docs/superpowers/specs/2026-11-06-url-shortener-design.md`, section 10. **Design truth:** `DESIGN.md` and
`PRODUCT.md` at the repo root. **Foundation interfaces:** `docs/superpowers/plans/2026-11-06-foundation.md`, Tasks
3–6.

## Global Constraints

- **Run phases in order:** Phase 1 (Tasks 1–3) runs first, as a single agent. Phase 2 (Tasks 4, 5 and 6) runs as
  three parallel agents, each touching **only** the files its task lists. Phase 3 is the controller's polish pass.
- **impeccable:** run `impeccable context` once per agent (see `~/.claude/skills/impeccable/SKILL.md`, "Setup"), and
  read its `reference/craft-floor.md` before the first UI edit. The mode is **Operate**. Don't run `init` or
  `document`: `PRODUCT.md` and `DESIGN.md` already exist.
- **Tokens:** use them only through CSS variables or Tailwind theme classes, never colour literals in components.
- **Colours:** no green, no violet, no gradients, no shadows at rest. Blue is the only interactive colour.
- **Sizing:** mobile-first. Design at 360px first, then `md` (768px) and `lg` (1024px). Every target is at least
  44px. Inputs use 16px text.
- **Numbers:** slugs, short URLs, counts and list dates use `font-mono tabular-nums`.
- **Dates:** **no hydration mismatches.** Any date or relative time renders through `<LocalTime>` (Task 1).
- **No new runtime dependencies** beyond what the shadcn CLI adds in Task 1. Charts are hand-built SVG or divs, not
  Recharts.
- **Visible text:** use the exact strings in this plan where one is given.
- **Branding:** the brand name comes only from `src/config/brand.ts` (`brand.name = "Snip"`).
- **Done means** `pnpm typecheck && pnpm lint && pnpm test && pnpm build` pass.
- **Commits:** one per task, Conventional Commits, **no `Co-Authored-By` trailer**.

## Review Focus

1. **Hydration:** dates and "Expires in …" can differ between server render (UTC) and the browser's time zone. Task 1
   adds `<LocalTime>` and `useHydrated`, Task 2 tests the formatters with an explicit `timeZone`, and Tasks 5 and 6
   must use `<LocalTime>`.
2. **Rate-limit UX:** the countdown has to reach 0 and re-enable the button, and a `null` retry time must still give
   a usable message. Tested in Task 2 (`secondsLeft`, `rateLimitMessage`) and exercised in Task 4 with
   `https://ratelimit.test/x`.
3. **Back button on phones:** with `?link=` open, Back must close the sheet and not leave the page. Task 6 Step 3.
4. **Long or odd targets:** a target longer than 120 characters must wrap in the sheet and truncate in rows without
   pushing the layout wider than 360px. The fixture includes one; checked in Tasks 5 and 6.
5. **Share on desktop:** if `navigator.share` doesn't exist, the Share button must not render at all, not render and
   then fail. Task 1 (`ShareButton`).
